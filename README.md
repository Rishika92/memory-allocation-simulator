
# Memory Allocation Simulator (C++)

A console-based C++ program that simulates classic **memory allocation strategies** using a linked-list memory arena.

##  Features: 
- Total Memory: **1024 MB**
- Allocation Policies:
  - First Fit
  - Best Fit
  - Worst Fit
  - Next Fit
- Dynamic memory split and merge
- Interactive menu (run again / new input / exit)
- Clear memory map visualization
- it runs forever until you select exit in interactive menu.
